## 已部署行为

创建订单、展示收款码、提交凭证及确认到账不依赖模型服务是否开通。每笔实际到账只记录一次；提交付款截图不会自动变成到账。生产已就绪时，确认到账后自动入队；否则保留待交付订单。

业务后台可上传经核对的方向图与 3 条建议，交付到原客户订单页。未付款、建议不完整、生产仍运行、过期编辑均不得覆盖结果。重复提交同一反馈不产生重复版本；修订另存历史版本。

新的交付版本表只允许服务端访问。管理请求验证账户身份；客户结果使用独立订单访问密钥。收款接口未接通支付平台的到账通知，实际到账仍需核对。
