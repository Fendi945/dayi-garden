# DAYI Workflow 测试矩阵与评估表 V0.1
日期：2026-09-19

## 核心目标
不用旧工作流照抄照搬，而是借鉴其“结构、风格、最短路径”的经验，基于 2026 年最新可部署图像编辑能力，建立 DAYI 自己可验证、可迭代、可自动化的庭院专用工作流。

## 测试原则
- 优先测试现代“语言驱动图像编辑”，ControlNet / Depth / Edge 只在结构漂移时逐步加入。
- 同一案例、同一需求、同一 Prompt 版本、同一风格参考，才能公平比较。
- 每增加一个节点，都必须用结果证明其价值；提升不明显就删除。
- V1 只解决：真实庭院照片 → 1 张可信方向图 + 3 条建议。
- 正式生产前至少跨 3 种不同庭院复测。

## 结构硬门槛
出现任一情况直接不合格：
- 建筑主体明显改变
- 门窗、主要出入口被乱改或消失
- 围墙边界或主要场地轮廓严重漂移
- 透视明显崩坏
- 把客户真实院子变成完全不同的场地

产品定义：客户买的不是“幻想一个漂亮院子”，而是“我的这个院子，可以变成什么样”。

## DAYI_PROMPT_V0.1
1. 不可改变条件：保留建筑主体、门窗、围墙、主要出入口、摄影视角和真实空间比例。
2. 客户需求：从订单注入喝茶、儿童、宠物、隐私、排水、低维护、远景等。
3. DAYI 设计原则：自然、自由、真实、疏朗、留白、光影、低维护；避免过度硬化、堆砌、廉价统一色调。
4. 画面质量：真实景观摄影感、自然材质、合理植物尺度、真实自然光。

## DAYI_REFERENCE_V0.1
- 东方自然：留白、山石、自然植物、克制。
- 自然松弛：生活感、自然生长、丰富但不杂乱、可长期维护。
- 现代自然：功能清晰、材料简洁、植物柔化硬质边界、空间秩序明确。

## 结构控制升级规则
阶段 0：无附加控制。
阶段 1：当体块、围墙深度关系漂移时 + Depth。
阶段 2：当门窗、墙线、铺装边界仍不稳定时 + Edge / Lineart。
删除规则：提升不明显或美感明显下降，则移除该节点。

## 从测试到生产的验收门槛
1. 第一轮 A/B：同一订单 12 张，选主模型与输入策略。
2. 第二轮 C/D：只针对结构问题逐级加约束。
3. 第三轮跨案例：至少 3 种不同类型庭院复测。
4. 记录平均结构得分、总分、生成时间、失败率、单张 GPU 成本。
5. 达标后冻结参数，命名 DAYI_GARDEN_WORKFLOW_V1.0，再接入 Supabase 自动流水线。
