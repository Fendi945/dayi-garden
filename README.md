# DAY1 Garden Public Frontend

This public repository contains only customer-facing frontend code, public brand assets, and tests required to keep those public routes working.

Commercially sensitive material is intentionally excluded, including:
- internal architecture and Agent protocols;
- product roadmaps and internal discussions;
- private QA / workflow rules;
- core design decision systems;
- private prompts and production automation logic;
- customer data, financial records, credentials and secrets.

Private system assets are maintained separately and are not part of this public repository.

## Public entry

https://fendi945.github.io/dayi-garden/

## Development rule

Any file that would help a competitor reconstruct DAY1's internal operating system, product roadmap, quality system, or automation method must not be committed here.
